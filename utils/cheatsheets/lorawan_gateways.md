# Lorawan Gateway Troubleshooting Commands

## Diagnostics

### The following commands can be used to run diagnostics from existing shell scripts

**Diagnostics on ethernet interface**
```
curl -s https://raw.githubusercontent.com/asoles23/Cent/main/gateway_check.sh | sh
```
**Diagnostics on cellular interface**
```
curl -s https://raw.githubusercontent.com/WillDew-Net/ping-to-packet/refs/heads/main/lorawan/gateway_cellular_check.sh | sh
```
